# Лабораторна робота №2: Розробка політики безпеки на основі міжнародних стандартів

**Об'єкт дослідження:** Вебпортал особистого кабінету студента (*University Student Portal*).

## Структура проєкту
* `policy/01_Security_Policy.md` — проєкт Політики інформаційної безпеки (принципи захисту, контроль доступу RBAC, аудит і логування, відповідальність персоналу).
* `policy/AnnexA_Mapping_Notes.md` — матриця відповідності впроваджених контролів стандартам **ISO/IEC 27001:2022**, **NIST CSF 2.0** та **COBIT 2019**, аналіз прогалин (Gap Analysis).
* `governance/Policy_Update_Method.md` — методика регулярного перегляду та оновлення політики, тригери змін і матриця відповідальності (RACI).
* `audit/Internal_Audit_Procedure.md` — регламент проведення внутрішнього аудиту ІБ.
* `audit/Audit_Report.md` — звіт за результатами первинного аудиту середовища та рекомендації.
* `scripts/maturity_calc.py` — Python-скрипт для автоматизованого розрахунку індексу зрілості системи за 5-бальною шкалою.
* `assessment/Maturity_Assessment.md` — підсумковий звіт оцінки зрілості.

## Запуск скрипту оцінки зрілості
```bash
python3 lab2/scripts/maturity_calc.py
```
