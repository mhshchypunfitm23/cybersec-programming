# Звіт за результатами первинного внутрішнього аудиту

**Об'єкт перевірки:** Тестове середовище вебпорталу студента (Kali Linux / Docker-сегмент)  
**Аудитор:** Інженер з інформаційної безпеки (`student_sec`)  

## 1. Результати перевірки контролів

| № | Контрольний захід | Очікуваний стан | Фактичний стан | Статус |
| :--- | :--- | :--- | :--- | :--- |
| 1 | Мережева фільтрація (UFW) | Вхідний трафік заблоковано (`deny incoming`) | Активний, політика `deny (incoming)` застосована | **Відповідає** |
| 2 | Розмежування прав (RBAC / sudo) | Робота під окремим користувачем без прямого `root` | Створено `student_sec`, права `sudo` обмежено | **Відповідає** |
| 3 | Системний аудит (`auditd`) | Логування змін `/etc/passwd` та `/etc/sudoers` | Служба `active`, правила моніторингу працюють | **Відповідає** |
| 4 | Шифрування каналів та БД | Використання HTTPS/mTLS та TDE для БД | Увімкнено у цільовій архітектурі порталу | **Відповідає** |
| 5 | Автоматизація бекапів та тестування | Щоденні бекапи + тест відновлення раз на квартал | Бекапи налаштовані, регламент тестування відсутній | **Частково відповідає** |
| 6 | MFA для всіх категорій користувачів | Обов'язкова 2FA для адміністраторів і викладачів | Увімкнено лише для адміністраторів порталу | **Потребує доопрацювання** |

## 2. Рекомендації щодо посилення контролю
1. Запровадити обов'язкову двофакторну автентифікацію (TOTP / WebAuthn) для облікових записів викладачів, які мають право змінювати оцінки в електронній заліковій книжці.
2. Затвердити графік щоквартального тестового розгортання резервних копій бази даних у ізольованому середовищі.
3. Інтегрувати автоматичний сканер вразливостей коду (Bandit / Trivy) у процес розгортання оновлень порталу.
