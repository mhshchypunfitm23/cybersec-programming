# ПР №3-4. Реалізація симетричного, асиметричного та гібридного шифрування

## 1. Архітектура та модулі проєкту
* `sym.py` — модуль симетричного шифрування (**AES-GCM** та **AES-CBC + HMAC-SHA256**), сховище ключів (`SymKeyStore`) із генерацією через `PBKDF2HMAC` + випадкову сіль (`salt`, 16 байт) та підтримкою ротації версій ключів.
* `asym.py` — модуль асиметричної криптографії (**RSA** 2048/3072/4096 біт): генерація ключової пари, захищений експорт приватного ключа у форматі PKCS#8 PEM, шифрування **RSA-OAEP (SHA-256)** та цифровий підпис **RSA-PSS**.
* `hybrid.py` — модуль гібридного шифрування: генерація одноразового сесійного ключа AES-256, шифрування даних через **AES-GCM** та захист сесійного ключа публічним ключем отримувача **RSA-OAEP**.
* `cli.py` — консольний інтерфейс (CLI) із валідацією вхідних ключів, обробкою виняткових ситуацій (пошкоджені дані, невірний MAC/тег автентифікації) та вбудованим бенчмарком (`bench`).
* `logger.py` — система структурованого журналювання подій криптографічних операцій у форматі JSON Lines (`logs/security_audit.jsonl`).

## 2. Генерація та ротація ключів
1. Під час створення ключа (`sym new --label portal_key`) генерується 256-бітний майстер-секрет через `secrets.token_bytes(32)` і 128-бітна сіль (`salt`), після чого через `PBKDF2HMAC` (100 000 ітерацій SHA-256) формується робочий ключ.
2. Повторний виклик `sym new` із тією самою міткою автоматично збільшує версію ключа (`v1 -> v2`), забезпечуючи планову ротацію без втрати метаданих.

## 3. Висновки щодо продуктивності та безпеки
* **AES-GCM** працює швидше за **AES-CBC + HMAC**, оскільки поєднує шифрування та автентифікацію даних в одному проході (AEAD) і підтримує апаратне прискорення AES-NI.
* **RSA** має значно більший час генерації ключів та обмежений розмір блоку шифрування, тому в реальних системах використовується виключно у **гібридній схемі** (для обміну сесійними ключами та цифрового підпису).

## 4. Приклади запуску
```bash
python3 cli.py sym new --label portal_key
python3 cli.py sym enc --label portal_key --in data/sample.txt --out outputs/sample.gcm --mode gcm
python3 cli.py rsa gen --priv keys/priv.pem --pub keys/pub.pem --password strongpass --bits 2048
python3 cli.py hybrid enc --pub keys/pub.pem --in data/sample.txt --out outputs/sample.hybr
python3 cli.py bench --sizes 100KB 1MB 5MB --modes gcm cbc --rsa-bits 2048 3072
```
