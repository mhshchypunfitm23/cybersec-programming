# ЛР №7. Розробка програмного брандмауера

## 1. Архітектура та принцип роботи
* **Проксі-брандмауер рівня користувача (`firewall.py`):** багатопотоковий TCP/UDP-фільтр трафіку (`8080/TCP -> example.org:80`, `5353/UDP -> 8.8.8.8:53`), який перевіряє кожне вхідне з'єднання за впорядкованою таблицею правил (`RuleSet`) без необхідності прав `root`.
* **Структура правил (`Rule`):** кожне правило визначається пріоритетом (`priority`, менше значення = вищий пріоритет), дією (`allow` / `deny`), підмережами джерела та призначення (`src_ip_cidr`, `dst_ip_cidr`), портами (`src_port`, `dst_port`), протоколом (`TCP` / `UDP`) та прапорцем активності (`enabled`).
* **Динамічне керування (Admin API на `127.0.0.1:8081`):** REST-інтерфейс (`GET /rules`, `POST /rules`, `PATCH /rules/<id>`, `DELETE /rules/<id>`) дозволяє додавати, змінювати та вимикати правила в реальному часі без зупинки служби.
* **Виявлення конфліктів:** при спробі додати правило з ідентичними параметрами мережі та пріоритетом система автоматично блокує дублювання і повертає попередження `duplicate_rule` (при однаковій дії) або `conflict_same_specificity` (при суперечливій дії `allow`/`deny`).
* **Журналювання та аудит (`logs/events.jsonl`, `analyze_logs.py`):** усі події пропуску та блокування пакетів записуються у форматі JSON Lines і аналізуються утилітою `analyze_logs.py`.

## 2. Запуск
```bash
python3 firewall.py --config config.json
python3 analyze_logs.py logs/events.jsonl
```
